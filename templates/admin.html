Signing keys (per tenant)

Each tenant has a signing key. Anything the platform issues for that tenant (credentials, export bundles) is signed with it, so any device can prove it's genuine and untampered. Rotating creates a fresh key; things signed with the old key stay valid — only new items use the new key.

Template protection (revocable biometrics)

Stored face/palm templates are kept in a scrambled, revocable form — a copy taken from the database or an export can't be matched anywhere else, and can be cancelled like a password. Reissue re-scrambles everything: old copies stop working instantly, and enrolled people keep verifying with no recapture.
